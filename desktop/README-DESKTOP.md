# JOUD Desktop

غلاف سطح مكتب (Electron) لنظام JOUD **الحالي** دون أي تعديل عليه. النافذة تفتح نفس رابط WAMP الذي تستخدمه في المتصفح (`http://localhost/joud/`)، فيبقى Apache وPHP وMySQL وقاعدة البيانات في WAMP كما هي، وتبقى نسخة المتصفح تعمل بالتوازي.

```
JOUD.exe → نافذة Electron → http://localhost/joud/ → Apache/PHP (WAMP) → MySQL (WAMP)
```

## التشغيل
1. تأكد أن WAMP يعمل (الأيقونة خضراء). إن لم يكن يعمل، يحاول JOUD تشغيل `wampmanager.exe` تلقائيًا من `C:\wamp64` أو `D:\wamp64` (وأمثالها) وينتظر حتى 60 ثانية.
2. شغّل `JOUD.exe` → تظهر صفحة تسجيل الدخول الحالية.
- إن كانت خدمات WAMP لا تبدأ تلقائيًا مع Windows فقد تحتاج تشغيل WAMP مرة يدويًا ثم الضغط على «إعادة المحاولة».

## الإعدادات (اختيارية)
ملف `%APPDATA%\JOUD\config.json` (يُنشأ تلقائيًا عند أول تشغيل):
```json
{ "url": "http://localhost/joud/", "startWampIfDown": true, "waitSeconds": 60 }
```
غيّر `url` إن كان Apache على منفذ آخر (مثل `http://localhost:8080/joud/`) أو كان WAMP في مسار غير معتاد (`"wampManagerPaths": ["E:\\tools\\wamp64\\wampmanager.exe"]`).

## الاختصارات
`F5/Ctrl+R` إعادة تحميل · `Ctrl+P` طباعة · `Ctrl +/-/0` تكبير/تصغير · `F11` ملء الشاشة · `Alt` إظهار القائمة.

## البناء (على Windows)
```
build-windows.bat
```
الناتج في `dist\`: `JOUD.exe` (محمول) و`JOUD-Setup.exe` (مثبّت مع اختصار سطح المكتب).
أو يدويًا: `npm install` ثم `npm test` ثم `npm run dist`. يتطلب Node.js LTS.

## سلوك مهم
- **الجلسة:** كوكي الجلسة مؤقتة كما في المتصفح؛ إغلاق التطبيق = تسجيل خروج.
- **الروابط الخارجية** تُفتح في المتصفح الافتراضي، ولا يتنقل التطبيق خارج `/joud/`.
- **PDF/CSV:** الملفات التي ينزّلها النظام تُحفظ عبر نافذة «حفظ باسم» ويظهر إشعار عند الانتهاء.
- لا يُعرَض MySQL ولا تُخزَّن بيانات قاعدة البيانات داخل التطبيق؛ تبقى في `config/config.php` كما هي.
- لم يُعدَّل أي ملف من النظام الأصلي. لإزالة Desktop احذف مجلد `desktop/` فقط.
